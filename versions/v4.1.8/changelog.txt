# Prominence II: Hasturian Era
**v4.1.8 - No more awakening, more Waystones**

## Changes
Awakening has finally been disabled! We had a breakthrough and it is now impossible to use a non 8/8 weapon for your artifacts.
What now? This largely only affects Lichblade and Dormant relic. You can Awaken it now through a recipe, which helps with visibility, but also use the runic forge. You can no longer put others into the runic forge. This unfortunately also has the effect that you cannot remove runes anymore. This may be fixed in the future but is a necessary sacrifice. 
Old Artifacts now also become fully awakened retroactively, if you have them in your inventory. 
Artifacts can no longer have runes, having runes on them will void them upon updating.
